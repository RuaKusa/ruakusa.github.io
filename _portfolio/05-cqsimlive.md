CQSimLive extends CQSim with an end-to-end dashboard layer for scheduling analysis, worklog metrics, and recommendation output. The public repository includes the simulator source, dashboard components, preprocessing logic, and documentation for the formulas and metrics used in the interface.

GitHub repository: [SPEAR-UIC/CQSimLive](https://github.com/SPEAR-UIC/CQSimLive)
